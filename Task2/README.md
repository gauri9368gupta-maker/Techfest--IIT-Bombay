# 🌌 DRIFT° — A Parallax Journey

> **Scroll into the unknown.**

DRIFT° is an immersive, interactive parallax web experience designed around the joy of scrolling and visual storytelling.

The website transforms ordinary scrolling into a digital journey where different visual layers move at different speeds, creating a sense of depth, motion, and exploration. Each section introduces a new part of the journey with animated landscapes, floating elements, glowing orbs, planets, stars, and interactive visual effects.

## 🧭 Website Journey

DRIFT° is divided into five visual layers:

### 01 — The Beginning

The hero section introduces the journey with:

- Animated mountains
- Stars
- Sun
- Parallax text
- Scroll indicator
- "Begin" CTA

> **Scroll into the unknown.**

---

### 02 — Slow Down. Look Closer.

The first story section demonstrates how different movement speeds create depth.

It includes:

- Floating orb
- Animated content
- Floating cards
- Multiple parallax layers

> **Depth appears when things move differently.**

---

### 03 — Another Orbit

The experience transitions from landscapes into a futuristic space environment.

Features include:

- Planet visualization
- Orbital rings
- Satellite element
- Glowing background
- Layered parallax movement

> **There is no destination here. Just momentum.**

---

### 04 — Motion Makes Meaning

This section focuses on the philosophy behind the experience.

It demonstrates how animation and movement can give a website:

- Space
- Direction
- Personality
- Visual storytelling

> **Make the interface feel alive.**

---

### 05 — The Finale

The journey concludes with a simple message:

> **Keep wandering.**

Users can restart the experience using the **Restart Journey** button and return to the beginning.
